# AnarchyGuardian

Плагин для защиты анархии от деструктивного поведения игроков. Предотвращает лаг-машины, дюпы и анализирует подозрительную активность.

## 🛡️ Возможности
- **Лимит сущностей в чанке**: Блокирует спавн, если в чанке превышен лимит (защита от лаг-машин).
- **Анти-дюп через выброс**: Запрещает спам выбросом предметов (проверка не более 5 предметов в секунду).
- **Очистка нелегальных стаков**: При входе игрока обрезает количество предметов в стаке до 64.
- **Защита от скопления контейнеров**: Запрещает ставить более 5 сундуков/шалкеров в радиусе 5 блоков.
- **Логирование**: Все подозрительные действия записываются в `guardian.log` с указанием времени и нарушителя.

## ⚙️ Установка
1. Скачайте `AnarchyGuardian.jar`.
2. Поместите в папку `plugins`.
3. Перезапустите сервер (Paper 1.21+).
4. Настройте лимиты в коде (константы `MAX_ENTITIES_PER_CHUNK` и `MAX_DROPS_PER_SECOND`).

## 🧠 Технологии
- Java 25
- Paper API 1.21+
- Работа с `Async` задачами и файловым вводом/выводом.
